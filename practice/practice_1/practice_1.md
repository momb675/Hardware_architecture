# Отчет по выполнению заданий BIOS/UEFI (Lenovo BIOS Simulator)

**Устройство:** ThinkPad E14 Gen 4 (21E3, 21E4)
**Режим:** Graphics Interface Mode


## Задача 1. Навигация по основным разделам
**Информация из раздела Main:**
*   Версия UEFI: R1SETXXW
*   Серийный номер: PF12345
*   Тип CPU: Intel(R) Core(TM) CPU

![Задача 1 - Main](screen1.png)


## Задача 2. Смена порядка загрузки
**Ход выполнения:** Перешел в `Startup → Boot`. Переместил `USB HDD` на первое место (Position 1), `Windows Boot Manager` — на второе. Сохранил настройки клавишей F10.

![Задача 2 - Boot](screen2.png)


## Задача 3. Включение/выключение Secure Boot
**Ход выполнения:** Перешел в `Security → Secure Boot`. Проверил статус (On). Переключил на противоположный, затем вернул обратно.
**Зачем нужен:** Защищает от загрузки неавторизованного ПО (руткитов).

![Задача 3 - Secure Boot](screen3.png)


## Задача 4. Установка пароля супервизора
**Ход выполнения:** Перешел в `Security → Password → Supervisor Password`. Установил пароль `Test1234`. Проверил, что при изменении настроек запрашивается пароль. Затем сбросил его.

![Задача 4 - Password](screen4.png)


## Задача 5. Сброс на заводские настройки
**Ход выполнения:** Перешел в `Restart → Load Setup Defaults` (F9). Подтвердил сброс в появившемся окне (Yes). Настройки вернулись к исходным.

![Задача 5 - Restart](screen5.png)


## Задача 6. Управление встроенными устройствами
**Ход выполнения:** Перешел в `Config → USB`. Нашел настройку `Always On USB`. Отключил её (Off), затем включил обратно (On). 
**Точный путь:** Config → USB → Always On USB.

![Задача 6 - USB](screen6.png)


## Задача 7. Режим работы SATA/NVMe
**Ход выполнения:** В разделе `Config` на модели ThinkPad E14 Gen 4 отдельного пункта SATA/NVMe Mode не обнаружено (в списке только Network, USB, Keyboard, Display, Power, Beep, CPU, Thunderbolt, Setup UI). Это связано с использованием архитектуры NVMe, которая не требует выбора режима контроллера.



## Задача 8. Временное меню загрузки (эмуляция F12)
**Ход выполнения:** Перешел в `Startup`. Нашел опцию `Boot device List F12 Option`. Убедился, что она активирована (On). Разница: F12 позволяет выбрать устройство одноразово, не меняя постоянный порядок загрузки.

![Задача 8 - F12](screen8.png)


## Задача 9. Просмотр системных логов
**Ход выполнения:** Перешел в `Main`. Нашел строку `BIOS Event log`. Однако в данном симуляторе она не поддерживается (написано "Simulator not support"). Очистить логи в эмуляторе невозможно (на реальном устройстве это делается в Diagnostics).


## Задача 10. Полный сценарий: подготовка к переустановке ОС
**Ход выполнения:**
1. Сбросил настройки (`Restart → Load Setup Defaults`).
2. Включил Secure Boot (`Security → Secure Boot`).
3. Установил Supervisor Password (`Test1234`).
4. Поставил USB HDD первым в `Startup → Boot`.
5. Сохранил и вышел (F10).
6. Снова вошел, проверил настройки (скриншот ниже), сбросил пароль и вернул порядок загрузки.
