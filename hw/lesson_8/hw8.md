# Решение задачи: «Сборка и диагностика ПК без BIOS и доп. программ»

## Задание 1. Выбор набора

**1.1.** Все наборы подходят по форм-фактору (корпус поддерживает ATX/mATX/Mini-ITX). Ограничение не отсекает ни один набор.

**1.2.** **Набор C** — только один M.2 Key M. Второй NVMe некуда ставить; переходник PCIe→M.2 займёт единственный x1, и звуковой карте места не останется.

**1.3.** **Набор A** — условно не подходит: БП имеет один EPS 8-pin, а плата требует EPS 8-pin + EPS 4-pin. Для турбо 181 Вт одного 8-pin может не хватить. Также нужен переходник для 12VHPWR (RTX 4070). Расчёт: 181 + 200 + 50 = ~431 Вт (650 Вт хватает, но разъёмов мало).

**1.4.** **Лучший — набор A (i5-13600K + B760 ATX).** VRM 12+1 фаз с запасом для 181 Вт; B760 поддерживает XMP; два M.2 Key M для двух NVMe; слот x16 (electrical x4) для звуковой карты. Набор B не подходит: только один M.2 Key M (второй — Key E для Wi-Fi), второй NVMe некуда ставить.


## Задание 2. Линии PCIe

**2.1. Таблица (набор A):**

| Устройство | Слот | Источник | Версия | Линий |
|---|---|---|---|---|
| GPU | PCIe x16 (верх) | CPU | Gen5 (GPU Gen4) | x16 |
| NVMe №1 | M.2 Key M (верх) | CPU | Gen4 | x4 |
| Звуковая карта | PCIe x16 (electrical x4, низ) | Chipset | Gen4 | x4 |
| NVMe №2 | M.2 Key M (низ) | Chipset | Gen4 | x4 |

**2.2.** Физически влезет (слот x16 длиннее). Электрически заработает на скорости **x1** (своей родной). Правило: карта с меньшим числом линий работает в большем слоте, но на своей скорости; карта с большим числом линий в меньший слот не влезет.

**2.3.** Чипсет общается с CPU через **DMI 4.0 (~8 ГБ/с)**. Второй NVMe (до 7 ГБ/с) + сеть 2.5G (~0.3 ГБ/с) + USB 3.2 (~2.4 ГБ/с) суммарно превышают DMI → «бутылочное горлышко», скорость падает.

**2.4.** **Нет.** Key E - для Wi-Fi (PCIe x1 + USB), NVMe используют Key M (PCIe x4). Ключи несовместимы физически.


## Задание 3. Питание и VRM

**3.1.** Нажатие Power -> PS_ON# -> БП запускается, но PWR_OK не поднимается -> плата **удерживает CPU в сбросе** -> система не стартует, POST не выполняется. Остановка на этапе подачи питания.

**3.2.** 12 фаз распределяют ток (~140 А при 181 Вт) -> меньше нагрев, стабильнее напряжение. На 6+1 фазах (набор C) VRM перегреется -> **троттлинг CPU**, возможны нестабильность и выключение.

**3.3.** Подключить только EPS 8-pin **можно**. Для игр/стриминга хватит, но при длительной максимальной нагрузке возможен нагрев разъёма и **ограничение турбо-режима** платой.

**3.4.** ATX 24-pin - питание платы (+3.3V, +5V, +12V, -12V, +5VSB), ток до ~10 А на линию. EPS 8-pin - питание CPU (+12V, до ~18–20 А на линию). 24-pin не рассчитан на 140+ А процессора - VRM требует отдельного мощного канала +12V.


## Задание 4. Память

**4.1.** Без активации XMP/EXPO память заработает на **JEDEC: DDR5-4800 CL40**. UEFI применяет безопасный профиль. Потеря производительности в играх - 5–15%.

**4.2.** 4 слота - физически влезает. Но 4 модуля создают нагрузку на IMC -> **частота может упасть** (6000 -> 5200/4800). Производители плат часто указывают пониженные частоты для 4 модулей. EXPO может не заработать — откат на JEDEC или ручная настройка.

**4.3.** **Нет.** DDR4 и DDR5 имеют разные ключи (вырез) и электрически несовместимы (1.2 В vs 1.1 В, разная распиновка). Физически не вставится.

**4.4.** Тренировка DDR - подбор напряжений и таймингов для стабильной работы. При неудаче EXPO UEFI **откатывается на JEDEC** (DDR5-4800 CL40), чтобы система загрузилась.


## Задание 5. Smart-настройки

**5.1.** **Zero RPM** (порог 50-55°C) - в простое вентиляторы стоят, тишина. **Smart Fan Curve** (`40°C→25%`, `60°C→50%`, `75°C→80%`, `85°C→100%`) - под нагрузкой плавная раскрутка без лишнего шума.

**5.2.** Для Intel: **Adaptive Voltage + Undervolting** (offset −0.08 В). Эффект: температура −10…−15°C, частоты стабильнее (+100–200 МГц в длительной нагрузке), производительность не падает.

**5.3.** **BIOS Flashback:** скачать прошивку, переименовать по инструкции, записать в корень USB (FAT32). Подключить БП (24-pin + EPS), вставить флешку в спец. порт, нажать кнопку Flashback. Ждать ~5–10 мин. **CPU и RAM не нужны.**

**5.4.** Zero RPM — крайняя точка кривой Smart Fan (0% ниже порога). Плата сравнивает температуру с порогом: ниже — стоп, выше — работает по кривой. Если порог выше критической температуры VRM → **перегрев VRM**, троттлинг. Безопасно: порог <55°C.

## Задание 6. Диагностика

| № | Диагноз | Решение |
|---|---|---|
| 6.1 | Корпус поддерживает только Mini-ITX, mATX (244×244) больше | Заменить корпус или взять Mini-ITX-плату |
| 6.2 | GPU в слоте x4 от чипсета вместо x16 от CPU | Переставить GPU в верхний слот x16 (CPU) |
| 6.3 | 4 модуля не проходят тренировку EXPO | Отключить EXPO (JEDEC 4800), вручную снизить до 5200–5600, или оставить 2 модуля |
| 6.4 | VRM 6+1 не рассчитан на 181 Вт -> троттлинг | Плата с VRM 12+1 или ограничить турбо в BIOS |
| 6.5 | BIOS не поддерживает Ryzen 9000 | Прошить BIOS через **BIOS Flashback** без CPU |
| 6.6 | Вентилятор на 100%: сбита кривая / 3-pin в 4-pin / датчик | Проверить подключение, сбросить настройки вентиляторов, проверить датчик |
| 6.7 | Слот x16 (electrical x4) неактивен или отключён в BIOS | Проверить спецификацию, включить слот в BIOS, переставить карту |

## Задание 7. Схема сборки (набор A)
БП 650 Вт: 
ATX 24-pin --> плата (24-pin)
EPS 8-pin --> CPU (EPS 8-pin)
EPS 4-pin --> [НЕ ПОДКЛЮЧЁН — турбо ограничен]
PCIe 8-pin×2 --> 12VHPWR (переходник) --> GPU

Плата B760 ATX:
CPU LGA1700 <-- i5-13600K
DIMM <-- 2×16 ГБ DDR5-6000 CL30 (XMP)
PCIe x16 (CPU, Gen5) <-- GPU RTX 4070 (x16)
PCIe x16 (electrical x4, chipset) <-- Звуковая карта
M.2 Key M (CPU, Gen4×4) <-- NVMe №1 (1 ТБ)
M.2 Key M (chipset, Gen4×4) <-- NVMe №2 (будущий)
CPU_FAN <-- Кулер CPU (4-pin PWM)
SYS_FAN <-- Корпусные вентиляторы (4-pin PWM)
