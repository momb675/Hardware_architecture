# Путь работы с виртуальной памятью (по материалам презентации)

На основе слайдов презентации (особенно слайдов 13, 18–20) можно выстроить следующий логический путь работы с виртуальной памятью:

## 1. Предпосылка: нехватка оперативной памяти
Когда на компьютере одновременно запускается множество программ, суммарные потребности которых превышают физический объём ОЗУ (RAM), система сталкивается с ограничением ресурса (слайд 13).

## 2. Выделение места на диске
Под виртуальную память специально отводится пространство на жёстком диске (слайд 13). Это «расширение» оперативной памяти за счёт вторичной памяти.

## 3. Вытеснение неиспользуемых частей
Те части памяти (страницы/блоки), которые не используются определённое время, частями сбрасываются (переписываются) из ОЗУ в виртуальную память на диске (слайд 13). Это освобождает физическую RAM.

## 4. Динамическое освобождение ОЗУ
Благодаря виртуальной памяти система может динамически освобождать часть оперативной памяти для нужных в данный момент процессов (слайд 13).

## 5. Обращение процессора и подкачка
Когда процессору снова нужны данные, вытесненные на диск, они должны быть переписаны обратно в основную (первичную) память — только после этого ЦП может к ним обратиться (слайд 18, схема иерархии). Этот обмен «ОЗУ ↔ диск» и есть механизм подкачки.

## 6. Ускорение доступа через кэш
Чтобы сократить потери времени на обращение к памяти, между ОЗУ и процессором работает кэш-память (слайды 18–20): в неё загружаются наиболее часто используемые данные, что исключает необходимость поиска информации в больших массивах ОЗУ и ускоряет извлечение данных.

## Итоговая цепочка

**Нехватка ОЗУ → выделение области на HDD → вытеснение неиспользуемых частей в виртуальную память → освобождение RAM → подкачка нужных данных обратно в основную память → кэширование часто используемых данных для ускорения доступа.**

> Примечание: в презентации тема виртуальной памяти раскрыта кратко (слайд 13); детали (страничная/сегментная организация, таблицы страниц, алгоритмы замещения) в файле не рассматриваются — путь построен строго по имеющимся слайдам.
