## HDD vs SSD

| Параметр | HDD | SSD |
|---|---|---|
| **Принцип работы** | Магнитная запись на вращающиеся пластины | Запись на флеш-ячейки NAND, без движущихся частей |
| **Скорость чтения/записи** | ~80–280 МБ/с | SATA: ~500–550 МБ/с; NVMe: до ~7250 МБ/с |
| **Движущиеся части** | Есть (шпиндель, головки) | Нет |
| **Устойчивость к ударам** | Низкая (~70–80 G) | Высокая (до ~1500 G) |
| **Уровень шума** | Слышимый | Бесшумный |
| **Цена за 1 ТБ** | ~$12–25 (в РФ ~12 000 ₽) | Дороже, в 2026 выросла из-за дефицита NAND |
| **Срок службы / ограничения** | Механический износ, отказ внезапный, ~4 года | Ограничен ресурсом TBW, деградация постепенная, ~8 лет |
| **Пример использования** | Архивы, бэкапы, медиатека, NAS | ОС, программы, игры, ноутбуки, серверы |

## Определения (кратко)

**1. DDR** — Double Data Rate, удвоенная скорость. Передача данных дважды за такт — по фронту и спаду сигнала.

**2. DIMM** — Dual In-line Memory Module, двухрядный модуль памяти. Планка ОЗУ для ПК и серверов; для ноутбуков — SO-DIMM.

**3. Ранг (rank)** — группа чипов на модуле, работающих как один блок шириной 64 бита. Бывает одно-, двухранговый и т.д.

**4. CAS Latency (CL)** — задержка в тактах между запросом данных и их выдачей. Меньше CL — быстрее отклик.

**5. Тайминги** — набор задержек памяти в тактах (CL, tRCD, tRP, tRAS), например 16-18-18-38. Меньше — быстрее, но на практике разница мала.

**6. Двухканальный режим** — два модуля работают параллельно, пропускная способность удваивается (64 → 128 бит). Важен для встроенной графики и больших объёмов данных.
